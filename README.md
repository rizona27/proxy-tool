# 代理切换工具 (Proxy Tool) v1.01

Windows 平台 HTTP 代理一键切换工具。莫兰迪色系界面，**纯标准库零依赖**，支持系统托盘、归属地查询、双段延迟检测。

> **版本号说明**：全项目版本号只在 `version.py` 里定义一次。
> 改那一行，窗口标题、Readme 弹窗、托盘提示、复制信息以及打包出的 exe
> 属性页版本号都会自动跟着变。

## 功能

- **一键切换**：输入代理地址和端口，点击按钮或按 Enter 切换代理状态
- **多格式地址**：支持 IPv4、域名（`proxy.example.com`）、IPv6（`[::1]`）
- **智能输入**：输入 IP 自动补点分段（`1921681001` → `192.168.100.1`）；
  **TAB 逐段跳转**（输到 `192.168` 按 TAB 自动补点并跳到第 3 段，走到第 4 段末尾才切到端口框）；
  字符白名单过滤，只放行数字/字母/`.-_:[]`，空格、中文、`@#$%` 等一律输不进去
- **端口校验**：只接受 0-9 数字（其他符号在按键落地前就被拒绝），范围限制 1-65535，非法值输入框即时标红
- **全量校验才可启用**：地址与端口都合法时「启用代理」按钮才可点击，否则呈灰色禁用；
  地址非法（如只输到 `192.168.1`、或 `192.168.1.16` 越界）与端口越界都会持续标红，
  **切换焦点不会让红框消失**
- **启用即锁定**：代理生效时地址/端口转为只读且文字加深；未启用时可编辑、文字转淡
- **系统托盘**：最小化/关闭缩到托盘，右键菜单一键切换，双击恢复窗口
- **归属地查询**：自动查询代理服务器与出口 IP 的国家、城市（过长自动省略号裁切）
- **双段延迟**：TCP 到代理延迟 + HTTP 代理出口延迟
- **配置可还原**：关闭代理时恢复系统原有绕过列表与 PAC 设置
  （启用前的快照会落盘，即使中途退出或崩溃，重启后依然能精确还原）
- **记忆配置**：只在**成功启用**后记住当次的地址与端口，下次打开自动回填；
  从未成功启用过时，启动后地址与端口保持空白
- **崩溃可定位**：任何未处理异常都会写入日志文件，不再出现无信息的报错弹窗

## 系统要求

- **Windows 10/11（64 位）** —— 系统代理走注册表 `HKCU\...\Internet Settings`
- **macOS 11+（Intel / Apple Silicon）** —— 系统代理走 `networksetup`
- 打包版：无需安装任何环境
- 源码运行：Python 3.10+（需含 tkinter，python.org 官方安装包默认包含）
  - macOS 建议 `brew install python-tk` 补齐 tkinter
  - macOS 若想要托盘图标：`pip install rumps`（可选，未安装则自动降级为无托盘）

## 使用方式

### 打包版（推荐）

**Windows** —— 在 Windows 上执行：

```bash
pyinstaller --clean --noconfirm ProxyTool.spec
```

产出 `dist/ProxyTool.exe`，双击运行。首次启动请求管理员权限（刷新 WinInet 需要）。

**macOS** —— 在 macOS 上执行一键脚本：

```bash
chmod +x build_macos.sh
./build_macos.sh
```

产出 `dist/代理切换工具.app` 与 `dist/代理切换工具 v1.01.dmg`。
脚本会自动把 `app.ico`/`app.png` 转成 `app.icns`，再打包成 `.app` 并压缩为 `.dmg`。

> ⚠️ **`dmg` 只能在 macOS 上生成**。PyInstaller 不支持跨平台编译，
> Windows/Linux 无法产出 macOS 可执行文件 —— 这是苹果工具链的硬约束。

### 源码运行

```bash
python main.py
```

无需 `pip install` 任何依赖 —— 全部使用 Python 标准库（托盘除外，见上）。

## 核心概念：绕过列表（ProxyOverride）

这是本工具的关键机制，理解它才能正确配置内网直连。

### `<local>` 不等于「本地地址」

Windows 的 `<local>` 只匹配**不含点号的单标签主机名**（NetBIOS 名称），
**不包含任何 IP 字面量**。因此 `127.0.0.1`、`192.168.x.x` 必须显式写成通配符：

| 目标 | `<local>` 能否绕过 | 需要的规则 |
|------|-------------------|-----------|
| `http://tools/` | 能 | — |
| `http://127.0.0.1/` | **不能** | `127.*` |
| `http://192.168.1.5/` | **不能** | `192.168.*` |

工具默认已包含以下段位：

- RFC1918：`10.*`、`172.16-63.*`、`192.168.*`
- 回环：`127.*`
- CGNAT（Tailscale / ZeroTier）：`100.64-127.*`
- 链路本地：`169.254.*`
- IPv6：`::1`、`fc00::/7`、`fd00::/8`、`fe80::/10`

### 关于公网域名绕行

绕过的判定依据是**字面量主机名**，Windows **不会**先做 DNS 解析再比对 IP。
所以若 NAS 通过公网域名访问，即使该域名解析到内网 IP，请求依然可能走：

```
浏览器 → 代理 → 公网 DNS → 公网出口 → 路由器 NAT 回环 → NAS
```

**建议**：内网访问优先直接使用内网 IP（如 `192.168.1.1`），已被默认绕过规则覆盖，
不经过代理，自然是内网速度。若必须用域名，可在系统 hosts 或路由器 Split-DNS
中将其指向内网 IP，或在「绕过本地地址」开启后手动追加该域名到系统代理绕过列表。

## 快捷键

| 按键 | 功能 |
|------|------|
| Enter | 切换代理（启用/禁用） |
| Esc | 清空输入 |
| **TAB** | 地址框内**逐段跳转**（IPv4）；走到第 4 段末尾才切到端口框。域名/IPv6 直接切到端口框 |
| **Shift+TAB** | 反向跳回上一段；已在第 1 段则退回上一控件 |

### IPv4 逐段跳转说明

单框输入 IPv4 时，TAB 会在段之间移动而不是直接跳到端口框：

```
输入 192.16  ──TAB──▶  192.16.|        （自动补点，光标落到第 3 段）
输入 124     ──TAB──▶  192.16.124.|    （光标落到第 4 段）
输入 26      ──TAB──▶  （切到端口输入框）
```

若当前段为空（例如只输了 `10.` 就按 TAB），则直接切到端口框，不会重复补点。

## 排错

程序遇到未处理异常时，会弹出错误提示并写入日志：

```
Windows : %APPDATA%\ProxyTool\error.log
macOS   : ~/Library/Logs/ProxyTool/error.log
```

直接访问该文件即可看到完整堆栈，便于定位问题。

## 技术实现

- **GUI**：Tkinter + 自绘 Canvas 控件（圆角按钮 / 输入框 / iOS 药丸开关）
- **系统托盘**：
  - Windows：ctypes 直接调用 `Shell_NotifyIconW`，零依赖
  - macOS：优先 pystray，其次 rumps，都没有则无托盘（主功能不受影响）
- **系统代理**（全部收敛在 `platform_ops.py`）：
  - Windows：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings`
    + WinInet `InternetSetOptionW` 刷新
  - macOS：`networksetup -setwebproxy/-setsecurewebproxy/-setproxybypassdomains`
- **归属地**：ip-api.com 免费 API（urllib 异步线程）
- **延迟**：TCP socket（短超时轮询）+ urllib HTTP 往返测时
- **打包**：PyInstaller（Windows 版 UPX 压缩；macOS 版不打 UPX，避免签名/加载问题）

## 体积优化说明

`ProxyTool.spec` 中通过 `EXCLUDES` 排除了全部未使用的大体积**第三方**模块：

```
PyQt5/PyQt6/PySide2/PySide6、numpy/scipy/pandas/matplotlib、
PIL/cv2、setuptools/pip/wheel、unittest/idlelib/lib2to3、
sqlite3/multiprocessing/asyncio/lzma/bz2/xml/xmlrpc、
win32com/pywin32/pystray ...
```

⚠️ **关键教训：绝对不要排除标准库。**
`urllib.request` 的依赖链会用到 `email.message`、`http.client`、`ssl`、
`hashlib`、`logging`、`uuid`、`base64` 等。一旦排除，打包后的 exe
会在发起归属地/延迟请求时直接崩溃，并弹出无信息的
`Failed to obtain/convert traceback!`。
PyInstaller 本身只会打包被真实引用的模块，保留标准库几乎不增加体积。

配合 `upx=True` 压缩，最终单文件约 **12 MB**（原 PyQt5 版约 39 MB，↓69%）。
